# أذكار يومية

برنامج للأذكار اليومية: أذكار الصباح والمساء والنوم وأذكار بعد الصلاة، مع ذكر مصدر كل ذكر، وبنود لمحاسبة النفس آخر اليوم.

## المميزات
- يعمل على الموبايل والكمبيوتر
- يمكن تثبيته كتطبيق على الشاشة الرئيسية
- يعمل بدون إنترنت بعد أول فتح
